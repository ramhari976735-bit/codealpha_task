### Hotel Reservation System

A Java-based Hotel Reservation System developed as part of the CodeAlpha Java Programming Internship (Task 2). This application allows users to search for available rooms, make hotel reservations, manage bookings, and view reservation details through a simple console-based interface.

### Features

* Search for available rooms

* Book hotel rooms

* View reservation details

* Manage customer bookings

* Simple console-based interface

### Technologies Used

* Java

* Object-Oriented Programming (OOP)

* Arrays / ArrayLists

### How to Run

* Compile the Java file: `javac HotelReservationSystem.java`

* Run the program: `java HotelReservationSystem`
